# Suggested Learning Order

1. **OpenStack basics**

   * What is OpenStack?
   * Cloud concepts (IaaS)

2. **Core architecture**

   * Controller node
   * Compute node
   * Network node

3. **Core services**

   * **Keystone** – Identity and authentication
   * **Nova** – Virtual machine management
   * **Neutron** – Networking
   * **Glance** – Image service
   * **Cinder** – Block storage
   * **Swift** – Object storage
   * **Horizon** – Web dashboard
   * **Placement** – Resource tracking

4. **How services communicate**

   * APIs
   * Message queue (RabbitMQ)
   * Database (MariaDB/MySQL)
   * Scheduler
   * Hypervisor

5. **Deploy and practice**

   * Install a small OpenStack lab (e.g., DevStack or MicroStack)
   * Create networks, launch VMs, attach volumes, and assign floating IPs

This sequence builds a strong understanding of **how OpenStack is structured** and the **responsibilities of Virtual Machines, Networking, Storage, and related services** before moving on to deployment and operations.
